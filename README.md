# Систем Пласт — премиальный сайт с автоматизацией

Сайт для компании **«Систем Пласт»** (Караганда): пластиковые окна, балконы, двери, витражи с 2003 года.
Сделан «под ключ» — от премиального дизайна до автоматизации заявок.

---

## 🚀 Как запустить (2 минуты)

Нужен только установленный **Node.js 18+** (проверено на 22). Никаких `npm install` — зависимостей нет.

```bash
node server.js
```

Открыть:
- **Сайт:** http://localhost:3100
- **Админ-панель:** http://localhost:3100/admin — пароль по умолчанию `sistem2026` (меняется в `config.json`)

Для остановки — `Ctrl + C`. Порт меняется в `config.json` → `"port"`.

## ⚙️ Настройка

Файл `config.json` (образец — `config.example.json`; файл не обязателен — без него сервер запустится со значениями по умолчанию):

```json
{
  "port": 3100,
  "adminPassword": "sistem2026",
  "telegram": { "botToken": "", "chatId": "" },
  "webhookUrl": ""
}
```

### Подключить Telegram-уведомления (5 минут)
1. Напишите в Telegram боту **@BotFather** → `/newbot` → получите **токен** (вида `123456:ABC…`);
2. Напишите боту **@userinfobot** → он покажет ваш **chat_id**;
3. Вставьте оба значения в `config.json` в поля `botToken` и `chatId`;
4. Перезапустите сервер: `node server.js`. Теперь каждая заявка приходит в Telegram моментально.

### Демо-заявки для админки (по желанию)
```bash
npm run demo-leads        # добавит 6 тестовых заявок
```

## 🌍 Публикация в интернет

Сайт легко размещается на любом хостинге с Node.js (**Railway, Render, VPS**) или прямо из папки:

```bash
# на сервере
node server.js
```

Для домена вроде `sistem-plast.kz` настройте reverse-proxy (nginx/caddy) на порт 3100 (или ваш из `config.json`) и HTTPS.
